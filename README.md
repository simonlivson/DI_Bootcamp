# Developers Institute — GenAI & ML bootcamp

Daily exercises and projects from my Developers Institute GenAI & ML bootcamp (cohort GenAI_AI#211_FT, graduating January 2027).

This repo is a record of the course work: Python, data analysis, machine learning, LLMs and AI agents, week by week. The projects I would point a hiring manager to first live in their own repos:

- [crypto-market-explorer](https://github.com/simonlivson/crypto-market-explorer) — hackathon project, with a [live Streamlit dashboard](https://crypto-market-explorer.streamlit.app/)
- [llm-as-judge-evals](https://github.com/simonlivson/llm-as-judge-evals) — prompt evaluation with a Gemini judge, [write-up on Medium](https://medium.com/@simon.livson/i-used-one-ai-to-grade-another-a-beginners-guide-to-llm-as-judge-5eda1d0177ee)
- [claude-skills](https://github.com/simonlivson/claude-skills) — reusable Claude Skills and Prompt Eval Lab
- [tic-tac-toe](https://github.com/simonlivson/tic-tac-toe) — week 1 mini-project, also as a [Hugging Face Space](https://huggingface.co/spaces/SimonIL/tic-tac-toe)

## How the repo is organized

Work is grouped by week and day, for example `Week4/Day3/`. Each day usually has Exercises XP and a Daily Challenge, and sometimes XP Gold or XP Ninja.
